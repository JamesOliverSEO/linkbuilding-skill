# Starter prompts

Copy one, swap in your own site and niche. Show these when the user asks what the skill can do.

## Not sure where to start

- "Build links to mysite.com. It's a travel blog. What should I do first?"
- "Look at mysite.com and tell me which link building tactic fits best."

## One per tactic

| Tactic | Prompt |
|---|---|
| Link reclamation | "Find links mysite.com has lost or that point to pages that no longer work, and help me get them back." |
| "Best X" listicles | "Find 'best [product type]' list articles that mention my competitors but not my product, mytool.com." |
| Unlinked mentions | "Find pages that mention [brand name] but don't link to mysite.com." |
| Broken link building | "Find broken link opportunities for mysite.com in the [niche] niche." |
| Competitor dead pages | "Find dead pages on competitor.com that still have backlinks, that I could replace." |
| Link gap | "Which sites link to competitor1.com and competitor2.com but not to mysite.com?" |
| Resource pages | "Find resource pages in the [niche] niche that would list my guide at mysite.com/guide." |
| Guest posts | "Find blogs in the [niche] niche that accept guest posts, and suggest topics I could pitch." |
| Moving Man | "[Tool or site] shut down or rebranded. Find sites still linking to it so I can offer mysite.com instead." |
| Skyscraper | "Find competitor.com's most linked articles and tell me which one I could beat." |

## Quick checks

- "Check these URLs and tell me which are broken: [list]"
- "Is olddomain.com expired or still registered?"
- "Does this page link to mysite.com? [URL]"
- "How many sites link to this page? [URL]" (a paid lookup, about $0.03; you'll be asked first)

## Picking up later

- "Here's my tracker CSV. Which prospects are due a follow-up?"
- "I sent these emails last week. Draft the follow-ups."
